
# Euler Orbit

An interactive, scroll-driven orbital visualization built with HTML, CSS, JavaScript, Canvas and GSAP.

Motion follows parametric elliptical paths with 3D rotations and perspective projection.

## Live website

https://hasibalam.github.io/Euler-orbit/

## Features

- Five animated orbital paths, stars, trails and planet glows
- Scroll-controlled scene transitions
- Rotating Quran quotations
- Responsive header and footer
- Embedded research report with open and download controls

## Local preview

Open index.html in a browser for a quick preview.

Internet access is required for CDN dependencies: GSAP and ScrollTrigger 3.12.5, Font Awesome 6.5.2 and Google Fonts.
